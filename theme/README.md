# Evangelion Omarchy theme

A dark Tokyo-3 command-center palette built around EVA-01 purple, acid green,
NERV red, and safety orange. Wallpapers in `backgrounds/` are newly generated
fan-art assets and do not include downloaded third-party artwork.

Install under `~/.config/omarchy/themes/evangelion` and apply with:

```bash
omarchy theme set evangelion
```

Cycle wallpapers with:

```bash
omarchy theme bg next
```
