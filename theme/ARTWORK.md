# Wallpaper artwork and provenance

The following wallpapers are original, prompt-generated artwork created for
this project with OpenAI's image generation tool on 2026-08-30. They are not
extracted animation frames or third-party stock art.

| File | Art direction |
|---|---|
| `backgrounds/5-eva-unit-00-prototype.png` | Yellow/orange prototype armor, black machinery, restrained blue optics |
| `backgrounds/6-eva-unit-00-refit.png` | Blue and white refit armor, cool cyan optics, clinical launch-bay light |
| `backgrounds/7-eva-unit-02.png` | Red/orange production armor, black machinery, restrained warning accents |

All three were generated as original stylized-concept illustrations using the
existing Unit-01 wallpaper only as a reference for rendering quality,
right-weighted composition, and negative-space placement. The prompts required
an empty dark left side, prohibited text, logos, insignia and watermarks, and
explicitly prohibited recreating copyrighted animation frames. Final project
assets are normalized to 1920x1080 PNG.
